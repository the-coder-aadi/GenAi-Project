Medhā AI

Your AI Study Saathi — an AI-powered learning platform built to help students learn from their own study material.

Medhā AI combines RAG, vector search, LLMs, PDF intelligence, AI quizzes, web search, and subscription payments into one learning experience.

✨ Features
📚 Chat with uploaded PDFs using RAG + Qdrant
🧠 Generate AI-powered summaries & quizzes
🌐 Web-assisted AI chat with Tavily
💬 General AI conversations using Groq
⚡ Usage limits with Redis
☁️ PDF storage with Cloudinary
💳 Subscription system with Razorpay
🗄️ Persistent data with MongoDB


🛠️ Tech Stack

Frontend
React · Vite · Tailwind CSS

Backend
Node.js · Express.js

AI & Intelligence
Groq · OpenAI GPT-OSS-20B (openai/gpt-oss-20b) · Qdrant · Tavily · Sarvam AI

Database & Infrastructure
MongoDB · Redis · Cloudinary

Payments
Razorpay
